## 🚀 1분 만에 GitHub Pages로 배포하기

1. **GitHub 저장소(Repository) 생성**
   - GitHub에서 새 리포지토리(예: `high1-course-designer`)를 생성합니다.
2. **코드 업로드 (터미널 기준)**
   ```bash
   git init
   git add .
   git commit -m "feat: 고교학점제 고1 학업설계 웹앱 초기 배포"
   git branch -M main
   git remote add origin https://github.com/<본인-깃허브-아이디>/<리포지토리-이름>.git
   git push -u origin main
   ```
   *(또는 GitHub 웹 화면에서 `index.html`과 `README.md` 파일을 직접 드래그앤드롭 업로드해도 됩니다.)*
3. **GitHub Pages 활성화**
   - 저장소 상단 **Settings** → 좌측 메뉴 **Pages** 클릭
   - **Branch** 설정을 `None`에서 `main` / `/(root)`로 선택 후 **Save** 클릭
   - 1~2분 후 `https://<본인-깃허브-아이디>.github.io/<리포지토리-이름>/` 주소로 즉시 사이트가 활성화됩니다.

## 🌟 핵심 기능 및 도서 판매 촉진(Lock-in) 설계

1. **3단계 과목 선택 시뮬레이터**
   - 7대 계열(공학, 의약보건, 자연, 사회, 인문, 교육, 예체능) 및 대표 학과 선택
   - 주요 교과군(수학, 과학/정보, 사회) 과목 선택 인터랙션
2. **도서 연계 블라인드 리포트 (Curiosity Gap)**
   - 목표 학과별 과목 적합도 점수 산출
   - 서울 주요대 학종 평가관이 권장하는 **필수 과목명 및 세특 키워드를 블러(Blur) 잠금 처리**
   - *"도서 142~147페이지 수록"*, *"부록 추천 도서 목록 수록"* 등 책의 페이지를 구체적으로 지정하여 도서 구매 필연성 유도
3. **도서 구매자 인증 모달**
   - 책을 구매한 독자는 책 속 퀴즈(예: 특정 페이지의 단어)를 입력하여 즉시 잠금 해제 가능
4. **온라인 서점(교보문고 등) 직통 구매 CTA**
   - 10% 할인 판매가 및 구매 링크 배치
